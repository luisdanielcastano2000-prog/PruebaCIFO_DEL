# Backend de Catálogo Tech

API REST hecha con **NestJS** y **Mongoose** (MongoDB). Recibe las peticiones del frontend en `/products` y guarda los productos en MongoDB.

Cómo arrancarlo, la API completa y el recorrido de un dato están en el **[README principal](../README.md)**.

Comandos útiles (dentro de esta carpeta):

| Comando | Para qué |
|---|---|
| `npm install` | Descargar las librerías (la primera vez) |
| `npm run start:dev` | Arrancar en modo desarrollo (se reinicia solo al guardar cambios) |
| `npm run lint` | Revisar el código en busca de errores típicos |
| `npm run format` | Ordenar el formato del código |
